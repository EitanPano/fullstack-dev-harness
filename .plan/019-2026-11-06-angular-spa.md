## Goal

A project can be generated and driven by the dev loop on an Angular 22 single-page app whose
structure is Angular's own (`core/`, `layout/`, `features/`, `store/`, `services/`, `shared/`,
`models/`, global SCSS), while the harness, QA, the screens checks and the brand generator keep
working unchanged. After this plan:

- the catalog ships `frontend/angular` 1.0.0 with the `i18n` and `pwa` flags and the stacks
  `angular-bun-express` and `angular-python-fastapi`, released as catalog v1.6.0;
- `docs/conventions.md › Frontend` is the ten framework-neutral invariants of ADR 0006 A1, and each
  template's `AGENTS.md` is the only place its layer map is written;
- this repository's generic texts name no React layer and point at the package's `AGENTS.md`;
- one bootstrap and one loop task on `angular-bun-express` are proven in a disposable clone.

## Assumptions

- ADR 0006 is the design. A1's ten invariants, A2's tree and reconciliations, A2.1's import
  table, A2.5's flag table and A3's file table are final; an implementer who finds one impossible
  reports it, and the session records the change here before anyone works around it.
- Versions are ADR 0006's table (registry, 2026-11-06), re-verified at C0 and pinned: Angular
  22.2.x, TypeScript 6.0.x (Angular's peer range; `react` and `next` stay on 5.9, per package),
  ESLint 10, `@hey-api/openapi-ts` 0.99.0 exactly, zod 4, `@ngrx/signals` 22, Transloco 8.4, CDK
  22.2, Playwright 1.65. Every new library is checked for peers and age (≥ 14 days) first.
- Catalog facts at d44a6fe: markers work in `.scss` and `.html`, not `.json`; `validate` checks the
  five frontend headings; a flag needs `summary` and `default`; a frontend cannot declare `auth`;
  `server:auth` and `server:database` are the cross-package selections; CI runs every case from
  `--list` on its own runner with 30 minutes each; a Postgres case publishes host port 5432.
- The server's auth endpoints are `/api/auth/register`, `/login`, `/refresh`, `/logout`, `/otp`
  and `/otp/verification`; the two OTP routes require an authenticated account, so `verify-otp` is
  a verification step behind `auth.guard`.
- Bun drives the Angular CLI through `ng`'s Node shebang (`bun run build`, `bun run test`); a run
  starts from the on-disk path spelling (`C:\Dev`, never `C:\dev`), the Bun path-case trap.
- Eitan's rules: Sonnet implementers and per-task reviews, one Opus final review; Conventional
  Commits; no commit, push, PR, merge or tag without his yes at the time; two repositories only.

## Risks

- **Hey API's Angular client is beta and documented against Angular 20.** Mitigation: S1 before
  anything else; the fetch-client fallback keeps the generated SDK and moves the behaviours into
  the client; an exact pin.
- **Bun driving the Angular CLI on Windows** (the Node shebang, the path-case trap, `ng test`
  under `bun run`). Mitigation: S2 on both platforms; every run from `C:\Dev`; the explicit
  `node … ng.js` fallback.
- **TypeScript 6.0 with angular-eslint, typescript-eslint and Prettier's Angular 22 template
  syntax.** Mitigation: C0 checks every peer range; exact pins; the boundaries test runs the real
  config.
- **The service worker in e2e and in `single` mode.** A registered worker could serve a stale
  shell or API answer during a test. Mitigation: Playwright `serviceWorkers: 'block'`;
  `ngsw-config.json` never caches `/api/auth/**` and gives `/api/**` a short `maxAge`;
  `registerWhenStable:30000`.
- **The `pwa` flag off still builds a worker file.** Accepted in 1.0.0 (ADR 0006); the backlog
  line waits on S4.
- **Ten cases stretch CI.** Mitigation: OQ2; `withApp` on three cases only; builds measured in S2.
- **Hebrew copy drafted by an implementer.** Mitigation: OQ3, one read by Eitan at G3; a wrong
  string is a patch.
- **Harness wording budgets.** `scripts/docs.test.mjs` caps the size-limited files; a generic
  sentence can be longer than the one it replaces. Mitigation: `node --test scripts/*.test.mjs` after every
  H1 edit; shorten rather than exempt.
- **The first Angular loop task exposes a rule the role agents misread** (plural layers, nouns as
  features). Mitigation: P1 runs before the lock bump is the default for new projects; findings
  become backlog lines, never silent fixes in the clone.
- **Two frontends drift in what the QA rubric calls things.** Mitigation: the Angular agents file
  uses the `ui-design` rubric's pattern names for its `shared/components/` (ADR 0006 A3).
