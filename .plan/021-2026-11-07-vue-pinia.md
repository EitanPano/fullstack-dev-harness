## Goal

A project can be generated and driven by the dev loop on a Vue 3 single-page app whose structure is
the Angular template's in Vue's spelling: `app/`, `core/`, `layout/`, `features/<noun>/`, `store/`
(Pinia setup stores), `services/` (a facade per server module over Hey API's fetch client),
`shared/`, `models/` and the global SCSS tree, with the `i18n` and `pwa` flags and the auth glue
behind `server:auth`, while the harness, QA, the screens checks and the brand generator keep
working unchanged. After this plan:

- the catalog ships `frontend/vue` 1.0.0 with the `i18n` and `pwa` flags and the stacks
  `vue-bun-express` and `vue-python-fastapi`, released as catalog v1.8.0;
- the Vue agents file is the only place its layer map is written, under the five headings, and it
  reads like the Angular one (page → store → service → SDK, the same copy keys, guards and session
  rules);
- this repository's generic texts name Vue wherever they enumerate the frontends (T11);
- one bootstrap and one loop task on `vue-bun-express` are proven in a disposable clone.

## Open Questions

None open. Both were answered at G1 on 2026-11-07 with the recommendations (Eitan's "approved"
named no other choice):

1. **Both flags in 1.0.0: yes.** The Angular template ships `i18n` and `pwa` and its code is the
   model for each (the Vue `i18n` is smaller: vue-i18n stays in both modes); a template that adds
   `i18n` later touches every template string. Cost: tasks C4 and C5 and three more cases
   (`i18n-off`, `pwa-off`, `flags-off`); Vite builds in seconds, so CI is not stretched. Not taken:
   1.0.0 without flags (seven cases, as React 3.0.0), each flag a later minor with its own cases.
2. **Forms: the `useZodForm` composable.** vee-validate's zod adapter peers zod 3 and vee-validate 5
   is a beta, so the industry default is unavailable. The composable of ADR 0008 T4 (about 150
   lines, the Angular semantics: first error after touch or submit, server field errors by path,
   the unmapped paths toasted once; the generated zod 4 schemas plug in directly) is built in C3.
   `@tanstack/vue-form` 1.33 stays spike S2's fallback if the composable passes ~200 lines or the
   aria wiring resists; a fallback taken is recorded here and in the ADR before C3 starts. Not
   taken: TanStack Form from the start (stable, Standard Schema, documented; a slot-based field API
   the agent must compose with our `form-field` anyway).

## Risks

- **Markers in `.vue` files.** A marked import inside `<script setup>` is impossible, and a
  trailing template marker can be moved by Prettier and then drops nothing, which only the
  `auth-off` build would catch. Mitigation: S6 before C1 (through Prettier); the block-only and
  `slots.ts` rules in the agents file; the V04 grep; `validate`'s dry run on every combination;
  the tool-change fallback named.
- **The cycle `client → config → auth interceptor → store`.** Mitigation: the interceptor is a leaf
  by lint (its own boundaries category), does the refresh with raw `fetch` and signals through
  `sessionLost`; S1 proves the import graph under Vite and Vitest.
- **Forms without a library.** The composable could grow past what an agent reads in one sitting.
  Mitigation: S2 with the ~200-line ceiling and TanStack Form as the fallback; G1 chose the composable.
- **vue-i18n under `script-src 'self'`.** The full build uses the message compiler. Mitigation:
  S3; the unplugin precompiles; `shell.spec` asserts no CSP violation; the Angular indirection is
  the fallback.
- **`vite-plugin-pwa` 2.0.0 is a new major** (35 days old at writing). Mitigation: S4; the
  hand-written `registerSW` fallback; `serviceWorkers: 'block'` in the e2e; the runtime rule
  allowlists `/api/health` only (ADR 0006 R36).
- **The guards await the session restore on a guarded deep link.** A hung API delays that page by
  up to 5 s. Mitigation: the cap, logged once; public pages never wait; the behaviour is Angular's
  with the mount no longer blocked.
- **The boundaries plugin and `.vue` imports.** A rule that cannot resolve `./app-header.vue` is
  silent. Mitigation: the TypeScript resolver with `extensions` including `.vue`; S5; every row
  seeded with a `.vue` import case.
- **The restyle on Reka** (focus trap in the drawer, `data-state` selectors). Mitigation: the
  Angular partials and React's Reka-shaped selectors are the model; each component's spec renders
  the real DOM; the shell e2e asserts the drawer.
- **Harness wording budgets.** `scripts/docs.test.mjs` caps the size-limited files. Mitigation:
  `node --test scripts/*.test.mjs` after every H1 edit; shorten rather than exempt.
- **The first Vue loop task exposes a recipe the role agents misread** (a page importing a
  facade, a store missing a returned ref, a `<style>` block). Mitigation: the lint rules make each
  an error; P1 runs before the lock bump is the default for new projects; findings become backlog
  lines, never silent fixes in the clone.
- **Docker down on the build machine.** The `--with-app` legs run in CI on the pull request;
  recorded in the ledger if so.
