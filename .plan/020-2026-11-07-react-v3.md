## Goal

A project can be generated and driven by the dev loop on a React 19 single-page app whose
structure is React's own and Eitan's: `app/`, `core/`, `layout/`, `features/<module>/`, `store/`
(Redux Toolkit), `services/` (RTK Query over the generated SDK), `shared/components/`, `models/`
and the global SCSS tree, while the harness, QA, the screens checks and the brand generator keep
working unchanged. After this plan:

- the catalog ships `frontend/react` 3.0.0 on the ADR 0007 tree, released as catalog v1.7.0, with
  the same stacks, cases, flags (none) and e2e journeys as 2.x;
- the React agents file is the only place its layer map is written, under the five headings;
- this repository's generic texts name no React 2.x layer, library or file (R10);
- one bootstrap and one loop task on `react-bun-express` are proven in a disposable clone.

## Risks

- **RTK Query under React Router loaders double-fetches or flashes.** Mitigation: S1 before C1;
  the fallback keeps the loader's subscription alive until the page mounts; the hook's
  `refetchOnMountOrArgChange: 30`.
- **The restyle breaks an accessibility or sizing check the e2e asserts** (44 px targets, 36/32
  densities, label-in-name, contrast). Mitigation: the SCSS mixins carry the numbers once;
  `tests/unit/density.test.ts` compiles the tree; the `brand` case runs the contrast checks; the
  Angular template's partials are the model for every pattern.
- **Radix's data attributes differ per primitive** and a state goes unstyled. Mitigation: one
  partial per component written against the rendered DOM in a unit test; the screens are read in
  the UI pass of P1.
- **ESLint 10 is refused by a plugin.** Mitigation: S3; the fallback is ESLint 9 as 2.x.
- **The serializability middleware warns on a model or an error.** Mitigation: `ApiError` is a
  plain object by design; S1 asserts no warning; a `Date` never enters the store (ISO strings).
- **A placeholder in `brand.css` breaks the in-place build or Vitest.** Mitigation: S2; Vitest
  does not process CSS by default; the in-place build was already impossible in 2.x.
- **The agents file recipe misleads the first loop task** (a page that imports `fetch`, a slice
  that copies server state). Mitigation: the lint rules make both errors; P1 runs before the lock
  bump; findings become backlog lines.
- **Harness wording budgets.** `scripts/docs.test.mjs` caps the size-limited files. Mitigation:
  `node --test scripts/*.test.mjs` after every H1 edit; shorten rather than exempt.
- **Docker down on the build machine.** The `--with-app` legs run in CI on the pull request;
  recorded in the ledger if so.
