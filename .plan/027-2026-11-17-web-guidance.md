## Goal

The frontend agent can look up a current web-platform guide (dialog and popover, form autofill
and validation, tables, motion, loading priority, sanitisation) before it hand-writes one, from
a pinned copy of the upstream guides, with telemetry off, inside the harness's own precedence
and report format. One real loop task then decides whether it stays.

## What upstream is (read 2026-11-17)

- A skill (`SKILL.md`) that tells the agent to run `npx -y modern-web-guidance@latest search`
  and `retrieve`; the npm package (1.0.1, Apache-2.0, Node 22+, 16.7 MB unpacked, no
  dependencies) holds 211 guides and a local search (embeddings and BM25, no network).
- Its own evaluation reports 57% → 88% on Claude Code. The tasks are vanilla HTML, CSS and
  JavaScript, graded by upstream.
- It cannot be taken as shipped, for five reasons:
  1. `@latest` runs unpinned remote code on every call, inside an agent that writes files.
  2. Telemetry is on by default: query text, guide ids and the agent's name go to a Google
     endpoint (`DISABLE_TELEMETRY=1` opts out). A private client project's nouns can ride in
     a query.
  3. Its description says "MANDATORY: Execute FIRST for all HTML/CSS" tasks. The guides are
     vanilla; the catalog's frontends ship framework primitives and a lint that fails a raw
     control outside the control directory. Followed as written, it fights the template.
  4. It appends a `### Modern Web Guidance` section to the response; a role agent's response
     ends with its `Verdict:` line and its report has fixed fields.
  5. The skill listing is at 3713 of 3800 characters; its description alone is about 900.

### H1: the script

- `search <query>` and `retrieve <id[,id]>` only. Any other sub-command exits 2: upstream's
  `install`, `uninstall`, `update` and `set-*` write files, and `update` spawns `npx`.
- One constant holds the exact version. The child is `bun x modern-web-guidance@<version>`,
  spawned with an argument array and no shell, `DISABLE_TELEMETRY=1` forced into its
  environment, no `--skill-version`.
- `retrieve` accepts ids matching `^[a-z0-9-]+$`, writes each guide to
  `.orchestrate/guidance/<version>/<id>.md` and prints the path and size. A file that exists
  is reused without a spawn.
- A failure (no network on first use, no `bun`, a non-zero child) is one line on stderr and
  exit 1, never a stack trace.
- Tests inject a fake runner, as `scaffold/fake-catalog.mjs` does.

### H4: docs

Net words on existing `.md` files are zero or fewer; each addition is paid for in the same file.

- New `.claude/skills/ui-design/platform-guidance.md`, at most 220 words, in the harness's
  words:
  - When: before hand-writing a control in the package's control directory, or a behaviour
    the package has no primitive for. Not for anything `frontend/AGENTS.md › Styling` names
    a component for, nor for config, tests or copy.
  - Budget: at most three searches and two guides per route; a guide is read once per task.
  - Precedence: the plan, then the package's `Styling` and control components, then
    `ui-and-styling.md`, then the guide. A guide is vanilla: it is adapted into the
    framework and the tokens.
  - Browser support as assumed above.
- `.claude/skills/ui-design/SKILL.md`: one pointer line, addressed to the frontend agent by
  name: the orchestrator and QA preload this skill too and are not to look guides up.
- `.claude/agents/frontend.md`: the pointer in step 4; the report gains
  `Guidance: <id> — <what it changed>, one per line | none | unavailable (<reason>)`.
- `AGENTS.md`: `guidance.mjs` joins the `scripts/` row (1197 of 1200 words today).
- `.claude/README.md › Running environment`: first use downloads the pinned package; how to
  bump the pin (read upstream's diff, repeat S1's telemetry check, one `chore(guidance)` PR).

## Risks

- A guide contradicts a template primitive (native `<dialog>` against the package's
  `ConfirmDialog`) — the precedence line; the control-directory lint still fails a stray
  control; P1 measures it.
- A compromised upstream release — an exact pin, bumped only by a reviewed PR. No integrity
  hash is checked (accepted; question 2b is the stronger form).
- Upstream renames the telemetry switch — the bump checklist repeats S1's check; a test
  cannot see it.
- Token and time cost: guides are 2 to 37 KB — the per-route budget and the cache; V10 caps it.
- No network on first use, or a sandbox — fail-open: `Guidance: unavailable (<reason>)`.
- The pin ages and the guides with it — bump when cutting a harness release.
- An agent recalls upstream's skill and spells `npx -y …@latest` — H3.
